TEST CASES: Mini E-Commerce System (PS 34)
Each test case starts with an empty product list unless stated.

TEST CASE 1: Normal input
  Menu option: 1
  Product name: Laptop
  Price: 50000
  Stock: 5
  Expected: Product added.
            ID: P101 | Laptop | Price: 50000 | Stock: 5

TEST CASE 2: Boundary / minimum input
  Menu option: 1
  Product name: Pen
  Price: 1
  Stock: 0
  Expected: Product added.
            ID: P101 | Pen | Price: 1 | Stock: 0
            Warning: Pen is out of stock.

TEST CASE 3: Invalid input
  (a) Menu option: 1, Product name: Mouse, Price: -500
      Expected: Invalid price. Price must be a positive number.
  (b) Menu option: 5, Product ID: P999
      Expected: Product P999 not found.

TEST CASE 4: Different valid scenario
  Start with: P101 | Laptop | Price 50000 | Stock 5
  (a) Menu option: 5, Product ID: P101, Quantity: 2
      Expected: Laptop x2 added | Amount: 100000
  (b) Menu option: 7
      Expected: Order total: 100000 | Laptop stock left: 3
  (c) Menu option: 3, Product ID: P101
      Expected: Product 'Laptop' deleted. Products left: 0
